# OCPP Backoffice Server (Home Assistant Addon)

Serveur OCPP 1.6 auto-hébergé (CSMS) avec API REST : plusieurs bornes, mode local ou relais par borne, comptes utilisateurs. Premier jet du "cœur backoffice" d'un écosystème de recharge personnel.
