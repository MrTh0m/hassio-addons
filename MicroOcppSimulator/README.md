# MicroOcpp Simulator (Home Assistant Addon)

Héberge [MicroOcppSimulator](https://github.com/matth-x/MicroOcppSimulator) en tant qu'add-on Home Assistant. Le simulateur lui-même n'a rien d'exclusif à Home Assistant : il se connecte en OCPP 1.6 à n'importe quelle supervision (Home Assistant, SteVe, ou tout autre central system OCPP), cet add-on ne fait que l'héberger commodément.
